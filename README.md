# 💰 AI 預算管家 (Desktop HUD + Android Home Screen Widget APK)

0 Token 實時追蹤並自動校準三大 AI 預算來源：
1. **Google AI Studio 餘額 (NT$)** 與本月快取節省金額
2. **Claude Platform API 剩餘點數 (US$)** 與過去 30 日消費
3. **Claude 訂閱額度（工作階段 % 與每週 % 分開顯示）** ＋ US$1,000 額度包
4. **Hermes 本地 `state.db` 逐筆 Token 實時增量**

## 📥 手機 APK 下載與安裝方式
1. 點擊本倉庫右側的 **Releases**（或上方 **Actions** -> 最新建置的 `ai-budget-widget-apk`）直接下載 `app-debug.apk` 到手機安裝。
2. 安裝後，在手機主畫面長按空白處 ➡️ 點選 **「小工具 (Widgets)」** ➡️ 找到 **「AI 預算管家」** 拖曳到桌面即可！
3. 同時支援 **家裡 Wi-Fi 區網直連 (`192.168.0.61:8765`)** 與 **外網 4G/5G 雲端加密快取自動切換**。
